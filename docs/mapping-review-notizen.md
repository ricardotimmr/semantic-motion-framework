# Mapping-Review-Notizen

Diese Datei sammelt Beobachtungen zu einzelnen Mapping-Einträgen, die nach der Preview-Prüfung eventuell angepasst werden müssen.

Ziel ist nicht, das Framework grundsätzlich zu verändern, sondern einzelne Parameter so zu schärfen, dass die intendierte Bedeutung in der Preview klarer wahrnehmbar wird.

## Vorgehen

Für jeden auffälligen Mapping-Eintrag können folgende Punkte notiert werden:

- Mapping-ID
- aktueller Eindruck in der Preview
- intendierte Bedeutung
- vermutetes Problem
- möglicher Anpassungsvorschlag
- Entscheidung: anpassen / offen lassen / bewusst beibehalten

## Template

```md
### mapping-id

Aktueller Eindruck:

Intendierte Bedeutung:

Vermutetes Problem:

Möglicher Anpassungsvorschlag:

Entscheidung:
```
