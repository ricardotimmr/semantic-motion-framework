# POC 02 - Mapping-Datenbank

Setup fuer den zweiten Proof of Concept aus `docs/pocs.md`.

## Ziel

Dieses Verzeichnis ist vorbereitet fuer die Validierung einer typsicheren Mapping-Datenstruktur und Lookup-Logik.

## Scope

Aktueller Stand: nur Projekt-Setup.

Noch nicht enthalten:

- TypeScript-Interfaces
- Mapping-Eintraege
- Lookup-Funktion
- Unit-Tests

## Befehle

```bash
npm install
npm run build
npm run lint
npm run test:run
```
