# POC 04 - Code-Export

Setup fuer den vierten Proof of Concept aus `docs/pocs.md`.

## Ziel

Dieses Verzeichnis ist vorbereitet fuer die Validierung von Framer-Motion- und CSS-Code-Export aus Mapping-Parametern.

## Scope

Aktueller Stand: nur Projekt-Setup.

Noch nicht enthalten:

- Generator-Funktionen
- Syntax- oder Snapshot-Tests
- Syntax-Highlighting
- Copy-to-Clipboard-UI

## Befehle

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test:run
```
